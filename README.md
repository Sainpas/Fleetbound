# Fleetbound ⚓

A warship recognition game where players identify ships from silhouettes, hints, and trivia.

## Concept

Fleetbound is designed around learning to recognize warships rather than simply guessing them once. Each ship can have its own recognition progress, statistics, badges, and ribbons.

## Planned features

- Ship identification from silhouettes
- Progressive hints
- Historical and technical trivia
- Per-ship recognition statistics
- Badges and ribbons
- Nation, class, and ship collections
- Difficulty levels
- Expandable ship database
